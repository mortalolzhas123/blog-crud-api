# Blog CRUD API

## 📌 Description
This project is a simple **Blog CRUD (Create, Read, Update, Delete) API** built using **Node.js, Express, and MongoDB**.  
It allows users to create blog posts, view them, update content, and delete posts.

---

## 🚀 Technologies Used
- Node.js
- Express.js
- MongoDB
- Mongoose
- HTML, CSS, JavaScript (simple frontend)

---

## ⚙️ Features
- Create a blog post
- View all blog posts
- Update a blog post
- Delete a blog post
- Simple frontend interface for testing
